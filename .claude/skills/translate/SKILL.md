# Итерация перевода

Единица работы — **один файл сценария или небольшая пачка**. Не браться за десять
файлов сразу: пользователь проверяет результат в игре параллельно, ему нужны
частые готовые куски, а не один большой в конце.

## 1. Понять, где работа остановилась

Прочитать [`docs/STATE.md`](../../../docs/STATE.md) — раздел «Следующий шаг».
Порядок файлов — как в прохождении: `sce1_c0_*` → `sce1_c1_*` → `sce1_c2_*` →
`sce1_c3_*`, параллельно логика (`logic01_*`) и предметы (`itm01_*`) того же участка.

Если пользователь назвал файл сам — берём его, но счётчик и «Следующий шаг»
в `STATE.md` всё равно обновляем от фактического состояния.

## 2. Поднять контекст — три файла, обязательно

- [`docs/glossary.md`](../../../docs/glossary.md) — согласованные имена и термины.
  Менять что-либо из таблицы нельзя без нового решения пользователя.
- [`docs/voices.md`](../../../docs/voices.md) — регистр речи каждого героя с цитатами
  из оригинала. Профили подтверждены целиком и «как есть»: **контрасты между
  персонажами держат юмор дела, сглаживать их нельзя.**
- [`docs/decisions.md`](../../../docs/decisions.md) — что уже согласовано и почему.

Пропуск этого шага — главный источник разнобоя между итерациями. Читать каждый раз,
даже если «вроде помню»: сессия могла смениться.

## 3. Достать сегменты

```bash
.venv\Scripts\python.exe tools\who.py sce1_c2_10 --todo
```

Показывает непереведённые сегменты файла с говорящим и английским текстом.
Атрибуция идёт по параметру кода `E101`, соответствие идентификаторов персонажам —
в [`voices.md`](../../../docs/voices.md).

Больше реплик персонажа для калибровки тона:

```bash
.venv\Scripts\python.exe tools\speakers.py --id 0002 --n 30
```

## 4. Перевести

Что держать в голове помимо смысла:

- **Голос говорящего.** Эджворт — книжная речь, полные конструкции, яд во внутреннем
  монологе (в скобках). Кей — подросток: восклицания, звукоподражания, простые
  конструкции. И так далее по `voices.md`. Кто с кем на «ты», а кто на «вы» —
  таблица пар в `decisions.md`.
- **Управляющие коды `{E108:0010}` обязаны сохраниться.** Порядок менять можно,
  набор нет. `{E108}` — пауза: ставить там же, где ритмически в оригинале.
  `{E041}`…`{E040}` — выделение: обернуть соответствующие **русские** слова,
  а не позицию из английского. Литеральная скобка — `{{`.
- **Две строки, 50 символов рабочий лимит, 53 жёсткий.** Перенос — `\n` внутри
  строки. Расставлять свободно: движок к английской разбивке не привязан.
  Не влезает — **сначала разбить на две строки, только потом сокращать формулировку**.
- **Кавычки — ёлочки.**
- `mode: 7` — узкое окно, лимит 24 символа.

### Идиому — не переводить словами

Устойчивый оборот в оригинале требует **своей** русской идиомы, а не разбора
английской по частям. Признак — оборот стоит целиком и не значит суммы частей:
`come now`, `it was nice while it lasted`, `kick in the teeth`, `turn my back on`.

Калька этого класса коварна тем, что **не выглядит ошибкой**: редких слов нет,
смысл читается, `check_len.py` зелёный — и только носитель слышит, что так не
говорят. Проверки на книжное слово её не ловят, она вся из обычных слов.
Три вопроса перед оборотом — [`decisions.md`](../../../docs/decisions.md#правило-которое-из-этого-следует).

Такие места идут в `polyglot.py` наравне с каламбуром — см. ниже.

### Непонятное место — сперва в другие локализации

Каламбур, выдуманное название, странная реалия, **английская идиома**, просто
непонятное слово: **до того как изобретать своё**, посмотреть, как поступили
официальные переводчики семи языков.

По идиомам вывод читается особенно прямо: **никто их не калькирует.** На
`It was nice while it lasted` французы дали «нам это дало отдохнуть», немцы —
«слишком хорошо, чтобы быть правдой», а японцы, корейцы и китайцы просто выбросили
оборот. Если все семь заменили оборот целиком — значит, и по-русски нужен свой,
а не сборка английского из деталей.

```bash
.venv\Scripts\python.exe tools\polyglot.py "sce1_c2_08.bytes|010021E6|18"
.venv\Scripts\python.exe tools\polyglot.py --find "Li'l Vee"
.venv\Scripts\python.exe tools\polyglot.py --block sce1_c2_08.bytes 010021E6
```

Две локализации сошлись на одном — почти наверняка так и надо. Все выбросили шутку —
она непереводима, держаться не обязательно. Немцы решили лучше — берём их приём.
Развёрнуто — в [`workflow.md`](../../../docs/workflow.md).

### Спорное — пользователю, до продолжения

Перевод каламбура, тон конкретной реплики, название улики, любое новое имя
(имена решает пользователь, разбор каламбуров — [`names.md`](../../../docs/names.md)).
Не копить к концу: спросить и продолжить с ответом.

**Вопрос строится без спойлеров** — короткая цитата, варианты, чем различаются.
Без того, чем сцена кончится и кто окажется прав: пользователь проходит игру
параллельно.

## 5. Влить и проверить

Переводы удобнее подавать патчем, а не править `work/case2.json` руками:

```bash
.venv\Scripts\python.exe tools\apply.py work\patch.json --dry-run
.venv\Scripts\python.exe tools\apply.py work\patch.json
.venv\Scripts\python.exe tools\check_len.py
```

Патч — JSON `{"идентификатор сегмента": "перевод"}` либо список записей с полями
`id` и `ru`. `check_len.py` **должен быть зелёным**: он сверяет длины строк,
число строк и сохранность кодов. Красный — чинить сейчас, не «потом».

Вывод гнать через `PYTHONIOENCODING=utf-8`, иначе кириллица падает на cp1251.

Строковые таблицы (улики, профили, логика, интерфейс) — **отдельный конвейер**:
`extract_strings.py` → правка `work/strings.json` → `check_strings.py` →
`build_strings.py`. `build.py` их не трогает.

## 6. Записать на диск — до конца ответа, а не сессии

Сессия обрывается на любом ответе; чего нет в файле, того нет. Прогнать список
целиком, каждый раз:

| Файл | Когда | Что писать |
|---|---|---|
| `docs/STATE.md` | **всегда** | Счётчик «N из 7402», «Следующий шаг», абзац об участке |
| `docs/glossary.md` | появилось имя, термин, улика, кличка | Строку в таблицу — сразу |
| `docs/decisions.md` | пользователь выбрал вариант | Вариант **и почему** |
| `docs/voices.md` | уточнилась манера речи, новый говорящий | Профиль и цитаты из скрипта |
| `git commit` | пачка готова и `check_len.py` зелёный | Суть участка и счётчик |

## 7. Отчитаться — без пересказа сюжета

В ответ идут: **какой файл, сколько сегментов, что осталось спорным**. Не пересказ
сцены. Сюжетные сводки пишутся в `STATE.md`, пользователю не зачитываются.

## Проверка в игре — периодически, не каждую итерацию

```bash
.venv\Scripts\python.exe tools\build.py
.venv\Scripts\python.exe tools\verify_build.py
.venv\Scripts\python.exe tools\build.py --install
```

`--install` требует **закрытой игры**. В игре: Options → Language → Deutsch.
Откат — `tools\restore.py`. Шрифты уже пропатчены, повторять не надо.
