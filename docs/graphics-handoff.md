## 2. Шесть правил пользователя — нарушать нельзя

**1. Сперва японский оригинал, потом рисовать.** У каждого ассета рядом
с `имя_eng` лежит вариант без языкового хвоста — японский. Английский это его
перерисовка с заменённой надписью. Иногда японский подходит целиком (термостат
уже говорит `20 ℃`), иногда с него берётся кусок, и **всегда** он показывает
точную границу правки. Это правило №3 проекта, применённое к картинкам.

**2. Нейросеть не правит картинку — она рисует её заново.** Просить у неё можно
**только слово на сплошном пурпурном `#FF00FF`**; игровую картинку давать лишь
как образец стиля. Вклейка — за нами. **Готовую картинку от генератора в игру
не ставить никогда.** Даже когда пользователь присылает «конечное фото» — оттуда
берутся только буквы.

**3. Набираемое набирать самому** — с 20 сентября 2026 через `tools/prints.py`
(раздел 4б): английская надпись снимается **подложкой**, а кегль и ширина берутся
замером с неё. Старый `relabel.py` (маска по цвету плюс затягивание дыры соседями)
остаётся для картинок, у которых подложки ещё нет; заливкой прямоугольника
не снимать никогда — она съедает стены и оставляет пятна.

**4. Ориентация.** В папках всё лежит **лицом вверх**. Бандлы хранят
по-разному: `gk2_upcut*` лицом вверх, `gk2_idcom` и `gk2_logickeyword` вместе
с двойниками `_trial` — вверх ногами (сверено 13 сентября 2026 по оригиналам
из `backup/`). Сторону решает `inject_localized.py` сам: той, какой лежат
**нетронутые** языковые варианты той же картинки в оригинале. Руками вертеть
не надо.

**Сверять только с тем, чего мы не писали.** До 13 сентября вставка брала
объект по адресу `_ger`, а в подменённом бандле тот вёл на английский: русское
ложилось в английские текстуры, и сторона сверялась с ними же. Так миниатюры
планов дела 1 и их карточка логики легли в игру перевёрнутыми, а «замер
12 сентября» объявил `_trial` лежащими лицом вверх. Из этого выросло правило
№13 в [`../CLAUDE.md`](../CLAUDE.md): картинку — пользователю, но только после
сверки с оригиналом.

**5. Надпись на картинке — это ещё одно хранилище имени.** Прежде чем
переводить, прогнать имя по репликам и таблицам. Так нашлась контора отца,
звавшаяся двумя именами сразу, и так же нашлась «Тортофеерия» (разбор ниже).

**6. Ни один файл, полученный из игры, в репозиторий не идёт.** В git только
разборы, задания и манифесты. `.gitignore` уже закрывает
`work/graphics_en/**/*.png`, `work/graphics_ru/**/*.png` и
`work/graphics_ai/**/*.png`.

**И общее правило проекта №4: спорные имена не выбирать самому.** Варианты
и разбор — в [`names.md`](names.md), выбор за пользователем.

## 4б. Новый порядок набора — с 20 сентября 2026

Для картинок, у которых есть подложка `text_mask.py` (семь языковых вариантов
с общим рисунком), старую пару `relabel.py` + `paste_art.py` заменяют два
инструмента. Разница не в удобстве, а в требованиях пользователя от 13 сентября:

```bash
make notes     # = prints.py -> notes.py -> paste_art.py (уменьшенные копии)
```

* [`tools/prints.py`](../tools/prints.py) — **печатные надписи**. Английскую снимает
  не маской по цвету, а **кусками английских чернил целиком**, на их место кладёт
  подложку; кегль, сжатие и контур берёт замером с самой английской надписи
  (тот же английский текст нашей гарнитурой подгоняется в рамку её чернил);
  длинное русское слово **сжимает по ширине**, рост держит — как немцы и французы
  («Springer» в росте «Knight»); пишет маску своих букв `<имя>_print_ink.png`.
  Гарнитуру подбирает замер: `prints.py <задание> --only <имя> --fonts` печатает
  все шрифты машины с кириллицей по совпадению с английскими буквами (IoU).
* [`tools/notes.py`](../tools/notes.py) — **рукописные пометки**. Снимает так же,
  набирает Ink Free по замеру руки (тело строки → кегль, рука против Ink Free
  на том же английском тексте → сжатие, штрих руки → контур), строки ставит
  на места английских, волнистое подчёркивание рисует сам. Мелкую копию плана
  не набирает, а **переносит буквы уменьшением** с большой картинки.
* Задание печатного — тот же `labels.json`, картинке добавляется `"по_оригиналу": true`,
  каждой надписи — `"англ"` (что стоит в оригинале) и, если надо, `"шрифт"` и `"по"`
  (лево/центр/право). `relabel.py` такие картинки пропускает.
* Задание пометок — `notes.json` рядом: рамки английских пометок, английские
  и русские строки по местам, `черты` (английское подчёркивание — из замера
  исключается) и `подчеркнуть` (под какими русскими словами вести волну).

Обе проверяются `check_pictures.py`, и обе берут запрет «буква на рисунке»
из одной с ней функции `untouchable` — набор не ищет место по своей мерке.
`--check` у обоих набирает заново в памяти и сверяет с лежащим PNG; оба стоят
в `check_all.py --full`.

## 5. Два инструмента

Запускать **строго в этом порядке**, если на картинке есть и набираемое,
и рисованное:

```bash
.venv\Scripts\python.exe tools\relabel.py   work\graphics_ru\case1\labels.json
.venv\Scripts\python.exe tools\paste_art.py work\graphics_ru\case1\art.json
```

`relabel.py` читает оригинал и пишет в `graphics_ru`. `paste_art.py` для той же
картинки должен взять за основу **результат первого**, иначе затрёт набранное —
для этого в его задании стоит `"основа": "готовое"`. Оба принимают `--only <имя>`.

### `relabel.py` — набрать надпись шрифтом

```json
{
  "cut00_007": {
    "fill": [50, 51, 58],
    "stroke": [31, 33, 33],
    "stroke_width": 0,
    "font": "consolab",
    "допуск": 45,
    "допуск_обводки": 25,
    "labels": [
      {"box": [372, 155, 508, 218], "text": "Ладья", "max_width": 136,
       "size": 50, "fill": [67, 68, 80]}
    ]
  }
}
```

`fill` работает дважды: это и цвет для маски снятия, и цвет букв по умолчанию.
`stroke_width: 0` — у печатных надписей обводки нет. В `text` знак `|` делит
на строки.

`size` — **точечное исключение** из правила «кегль общий на картинку»: нужно,
когда на картинке два настоящих размера шрифта (на плане охраны «Ладья» вдвое
крупнее шапки). Без `size` кегль подбирается общий — самый крупный, при котором
каждая надпись влезает в свой `max_width`.

### `paste_art.py` — вклеить нарисованную надпись

```json
{
  "cut00_010": {
    "основа": "готовое",
    "снять":   [{"box": [265, 230, 1100, 330], "fill": [189, 37, 37],
                 "stroke": [189, 37, 37], "pad": 6, "допуск": 45}],
    "вклеить": [{"art": "../../graphics_ai/case1/лист.png",
                 "отрезать": [{"ниже": [[420, 255], [1120, 142]]}],
                 "из": [60, 10, 1260, 305],
                 "кроме": [[460, 270, 1015, 375]],
                 "box": [276, 237, 737, 330]}],
    "вернуть": [{"box": [1160, 878, 1310, 995], "цвет": [189, 37, 37],
                 "допуск": 60}]
  }
}
```

| Ключ | Что делает и **зачем понадобился** |
|---|---|
| `снять` | убрать старую надпись маской и затягиванием соседями |
| `вклеить` | поставить нарисованную; `box` — рамка, пропорции сохраняются |
| `из` | вырезать кусок листа: нейросеть присылает несколько пометок на одном листе |
| `кроме` | замазать фоном прямоугольники внутри вырезки: пометки стоят лесенкой, и рамка вокруг одной прихватывает угол соседней |
| `отрезать` | замазать всё выше или ниже прямой через две точки: строки налезают друг на друга по вертикали, прямоугольником их не разделить |
| `поворот` | повернуть вырезку перед вписыванием в рамку |
| `взять`, `перекрасить`, `tol_in`, `tol_out` | оставить только пиксели около цвета букв. Нужно, когда нейросеть нарисовала слово **на плашке**, а плашку рисовал Capcom и её надо сохранить |
| `key`, `key_tol`, `despill`, `shrink` | ключ по фону: цвет, допуск, снятие пурпурной каймы, сжатие альфы |
| `вернуть` | вернуть кусок из нетронутого оригинала по цвету: стрелка от пометки к фигуре нарисована той же ручкой и идёт сквозь буквы, снятие откусывает ей хвост |
| `уменьшить` | собрать мелкую копию уменьшением готовой большой: на 158x158 набирать уже нечего |
| `как`, `якорь_там`, `якорь_тут` | взять задание другого файла и пересчитать все рамки по общему ориентиру |
| `допуск`, `допуск_обводки` | допуск маски снятия — на уровне картинки или отдельного `снять` |

**`как` — главная экономия.** Дело 1 повторяется само в себе: план охраны
в трёх файлах, газета в пяти, схема площади в четырёх. Размечается руками
**только первый файл**; для остальных хватает трёх строк с ориентиром (у планов
это лист бумаги, его рамка ищется как bbox белых пикселей). Ребёнок может
переопределять ключи родителя — у мелкой копии свой `допуск`.

## 6. Порядок сборки одной картинки

1. **Посмотреть японский вариант** — вдруг правка не нужна или нужна частично.
2. **Прогнать имя по репликам и таблицам** (правило №5): искать в `work/case*.json`
   и `work/strings.json` по английскому и по предполагаемому русскому.
   Разошлось — **это находка, нести пользователю**, а не решать самому.
3. **Наложить координатную сетку** на оригинал (шаг 100 по x, 50 по y, с подписями)
   и прочитать рамки глазами. Рамку старой надписи мерить **по самым тусклым
   буквам**, а не по тем, что читаются.
4. **Взять пробы цвета** — букв, обводки, фона — счётчиком частых цветов
   в области надписи. На глаз не угадывается.
5. Написать задание, прогнать, **посмотреть результат картинкой**, поправить.
   Первого раза не хватает почти никогда: закладывать два-три круга.
6. Записать на диск и закоммитить **своими путями**.

## 7. Восемь ошибок, которые уже сделаны — не повторять

**1. Разложил файлы по соседству имён, а не по тому, что нарисовано.**
`logic00_016_s` был записан в план от 19 марта, а на карточке `March 24`
и пометки 24-го числа. По тому списку в неё ушёл бы чужой почерк.
**Открывать и смотреть каждую картинку**, а не доверять порядку имён.

**2. Перевёл надпись, не прогнав имя по репликам.** `Cakestravaganza` в реплике
уже был «Тортжеством», а в задание на картинку ушла «Тортофеерия» — и нейросеть
успела её нарисовать. Повезло, что пользователь выбрал нарисованное; иначе две
картинки пришлось бы просить заново. **Прогонять имя до отрисовки, не после.**

**3. Решил, что старую надпись достаточно закрыть новой.** Русское «СТАЛЬНОЙ»
шире английского `STEEL`, но между букв у него дыры: **12% пикселей старого
слова** оставались видны. Замерено, не на глаз. Снятие обязательно всегда.

**4. Взял один допуск маски на все размеры.** На карточке 158x158 буква занимает
три пикселя и почти вся состоит из сглаживания; маска с допуском 45 не брала
ничего, английское осталось под русским, и надписи **задвоились**. Для мелких
копий допуск 70–105, и проверять глазами, а не полагаться на «отработало».

**5. Снял надпись прямоугольником поверх соседнего рисунка.** Красный конь стоит
в одной строке с пометкой, стрелка от пометки идёт сквозь буквы. Рамку резать
на полосы, стрелку возвращать через `вернуть`.

**6. Обрезал вырезку по видимой границе слова.** Строка на листе поднимается
вправо, и обрезка по `y=205` срезала верх у слов, которые там на `y=180`.
**Мерить экстремумы по столбцам кодом**, а не по картинке.

**7. Собирал мелкую копию тем же способом, что крупную.** На 158x158 набранное
превращается в кашу — там `уменьшить`. Но **не наоборот**: заменять бумагу
на уменьшённую большую в копии 300x300 нельзя, игра рисует её отдельно и резче
(расхождение 24 из 255).

**8. Написал правила из опыта разделом ниже промпта, а не в самом промпте.**
Пользователь читает раздел, а нейросеть получает блок. **Требование от 25 августа:
всё, что добыто опытом, идёт в копируемый блок.**

## 10. Проверка и установка

```bash
make check
```

```bash
make graphics-ru
```

`make check` — проверки перевода, графики не касается. **`make install` ставит
и русские картинки** — весь `work/graphics_ru/`, все дела, без флагов
(требование пользователя от 11 сентября 2026); `make graphics-ru` — только
картинки. **Игра должна быть закрыта**; откат — `make restore`.

Русские картинки ставит `tools/inject_localized.py`, без папки — весь
`work/graphics_ru/`. Бандл собирает из оригинала в `backup/`, размер приводит
к ассету сам, формат (BC7 или RGBA32) берёт у оригинала, сторону — по языковым
вариантам оригинала (правило 4 выше). Игроку те же картинки везёт патчер —
слоем, который снимает `make layers` (`tools/layer_localized.py`); листы для
показа пользователю — `work/graphics_layers/preview/` (правило №13).
На свежем клоне PNG нет (они в `.gitignore`), и установка текста из-за этого
не падает.

Проверять глазами: открыть готовый файл и посмотреть. Английского не должно
остаться **нигде** — смесь языков на экране это брак.

## 11. Работа вдвоём и окружение

Дерево может быть общим с другой сессией (она переводит дело 4). Перед коммитом —
`git status` и `git log --oneline -5`; в индекс класть **только свои пути**,
никогда `git add -A`. Чужие изменённые файлы не трогать.

Питон — только из venv проекта, Docker не предлагать. Вывод гнать через
`PYTHONIOENCODING=utf-8`, иначе кириллица падает на cp1251. Документы писать
питоном или файлом, а не эхом в bash: в тексте на каждой строке обратные кавычки,
и bash видит в них подстановку команд.
