Журнал теперь живой: одно окно, записи добавляются без переоткрытия; события
музыки, этапы и завершение имеют время. Ошибки данных, сборки, Tk-callback,
извлечения фона и музыки записывают полные Python traceback.
Ошибки необязательного оформления не останавливают установку.

Добавлена отдельная карточка «Проверка данных глав», главы1–5. До разрешения
установки читаются все пять JSON, проверяются номер главы, наличие непустого
списка записей, обязательных полей и заполненного RU. Ошибка запрещает старт.
Это проверка комплектности/формата, редакторскую вычитку она не заменяет.
Фактические объёмы записей:3700,7402,7198,5569,9162; общая механика отдельно.
Статусы проверяются по всем пяти главам. Этап GK1 называется «Язык первой игры»,
с пояснением «Немецкий → английский»; к главам GK2 он не относится.

Обычный запуск в Windows без аргументов открывает графическое окно. Кнопка
«Установить перевод» начинает прежний конвейер установки; до нажатия читаются
только ресурсы оформления. Если автопоиск не удался, доступен выбор папки игры.

Фон — исходная `map00` из `gk2_mapbg_trial`, извлекается во временную папку и
затемняется для читаемости. Музыка — `BGM_04` из `gk2_bgm_trial` (резервный
бандл `gk2_bgm`), декодируется в память. Громкость PCM снижена до 35%; кнопка
выключает и включает музыку, системная громкость не меняется. На завершении
музыка останавливается. Без ресурса или аудиоустройства установка доступна.
Игровые картинки и музыка в EXE не включаются.

Пять полос: реплики, таблицы, совместимость GK1, шрифты, графика и звуки.
События `args.progress` поступают из рабочего потока через очередь, интерфейс
остаётся доступным. Счётчики показывают реально обработанные файлы/бандлы.
До появления точного знаменателя движется неопределённая полоса. Общая полоса
считает долю выполненных этапов с одинаковым весом, а не оставшееся время.
Заливка плавно приближается к измеренному значению, внутри движутся диагонали.

В шапке названия сцен динамически берутся из `gk_common_title` в данных перевода:
только три заголовка начала первого дела. В карточках этапов декоративные
заголовки убраны после замечания пользователя: они выглядели как статус проверки
только первой главы. Там теперь пояснения реальной работы каждого этапа.
Игровая сборка работает с целыми бандлами. Имена последующих глав не показываются.

Команды из корня репозитория:

```powershell
.venv\Scripts\python.exe patcher/aai2ru.py --gui
.venv\Scripts\python.exe patcher/aai2ru.py --preview
.venv\Scripts\python.exe patcher/aai2ru.py --console --no-pause
```

`--check`, `--build-only` и `--uninstall` остаются консольными. Явное сочетание
этих режимов с `--gui`/`--preview` отклоняется. Во время установки закрытие
окна блокируется, чтобы не оборвать запись файлов; окно можно свернуть.

Код: `patcher/loading_ui.py`, `loading_assets.py`, `loading_audio.py`, события
в `aai2ru.py` и `steps.py`. Сборщик автоматически включает три новых модуля по
замыканию импортов; Tk/Pillow подхватываются PyInstaller. Исправлено разрешение
путей данных при относительном `--out` (относительно spec оно давало неверный путь).
