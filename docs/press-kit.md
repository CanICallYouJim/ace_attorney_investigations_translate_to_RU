# Раскадровка витрины: что снять для README

> Список кадров и сценарий ролика для главной страницы репозитория. Снимает
> пользователь, верстаю я. Зачем всё это и куда ляжет — [`release.md`](release.md).

Готовые файлы класть в **`docs/press/`**, имена — как в списке ниже. Отбирать,
обрезать и жать буду сам, так что лишний кадр не помеха: лучше два варианта одной
сцены, чем ни одного.

## Три правила съёмки

**1. Снимаем экраны, а не сюжет.** Витрина должна показать, что переведён каждый пласт
текста: реплики, плашка имени, улики, профили, логика, меню. Сюжет для этого не нужен
вовсе, а гость, зашедший поставить перевод, не обязан узнать из README, чем кончается дело.

**2. Только первая треть дела.** Ничего из финальных разоблачений: ни собранной
цепочки «Логики», ни полного списка улик (в названиях бывает половина развязки),
ни имён, которые всплывают только в конце.

**3. Ничего не подрисовывать.** Без рамок, стрелок, подписей и масштабирования —
кадр должен быть тем, что человек увидит у себя. Подписи добавлю в README текстом.

## Ролик, 30–45 секунд

Ритм важнее полноты: длинные паузы и чтение реплик целиком лучше вырезать.

| Время | Что происходит |
|---|---|
| 0:00–0:04 | Титульный экран |
| 0:04–0:10 | Настройки → язык → выбор русского, возврат в игру |
| 0:10–0:25 | Живой обмен репликами, два-три разных говорящих |
| 0:25–0:35 | Органайзер: улика с названием и описанием, или предъявление |
| 0:35–0:45 | «Логика» или осмотр места |

**Без звука.** Музыка игры — чужой контент, и на витрине она не нужна; в настройках
Game Bar снять «Записывать звук при записи игры».

## Технические требования

**Скриншоты.** Steam, клавиша `F12` (Steam → «Просмотр» → «Скриншоты» → «Показать на
диске»): снимает ровно кадр игры, без рамки окна. Формат — PNG, разрешение родное,
не менять и не обрезать.

**Ролик.** `Win+Alt+R` — запись активного окна, ляжет в `Видео\Клипы`. Настройки:
**720p, 30 к/с, стандартное качество** — 45 секунд выйдут примерно в 5 МБ. У GitHub
потолок 10 МБ на вложенное видео, и в него надо попасть. Если стоит OBS — тем лучше:
H.264, 30 к/с, битрейт 2500.

**Гифка.** Соберу сам из ролика, если в системе найдётся `ffmpeg`; иначе скажу, чем
сделать. Она нужна, потому что гифка играет в README везде и всегда, а видео —
только через ссылку.

## Как отдать видео для README

Файл в репозитории GitHub плеером не покажет — будет ссылка «скачать». Рабочий способ:

1. Открыть на GitHub «New issue» — **не отправлять**, просто открыть форму.
2. Перетащить `.mp4` в поле текста, дождаться загрузки.
3. GitHub подставит строку вида `https://github.com/user-attachments/assets/…` —
   скопировать её и прислать мне. Форму можно закрыть, файл уже загружен.
4. Эта ссылка отдельной строкой в README разворачивается в плеер.

## Что я сделаю с материалом

Отберу кадры, приведу к одной ширине, соберу гифку, разложу по разделам README
и напишу подписи. Присылать можно по одному, ждать полного комплекта не нужно —
витрина собирается из того, что есть, и дополняется.
