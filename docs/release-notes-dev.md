> Заведён 6 ноября 2026, когда README витрины (`release/README.md`) переписан
> под игрока: что это, как поставить, частые вопросы. Всё про процесс работы

## Как устроен шаблон

`release/README.md` — не готовая страница, а шаблон: `tools/publish_release.py`
(`write_showcase`) подставляет в него значения и кладёт результат в README ветки `main`.

| Подстановка | Откуда | В шаблоне сейчас |
|---|---|---|
| `{{segments_done}}`, `{{segments_total}}` | `slim_entries()` | да, «Что внутри» |
| `{{strings_done}}` | `slim_strings()` | да, «Что внутри» |
| `{{strings_total}}` | `slim_strings()` | нет: знаменатель включает отложенные музыкальные названия и имена галереи, игроку он только путает |
| `{{gk2_pictures_done}}`, `{{gk2_pictures_total}}` | `graphics_progress()` | да, «Что внутри» |
| `{{gk2_pictures_percent}}` | `graphics_progress()` | нет: хватает «N из M» |
| `{{gk2_materials_done}}`, `{{gk2_materials_total}}`, `{{materials_progress}}` | `graphics_progress()` | нет: 3D-материалы — внутренняя кухня; 2 из 2 закрыты 29 октября |
| `{{pictures_done}}` | `copy_layers()` | нет: число записей слоя, а не картинок для игрока |
| `{{built}}` | дата сборки | да, строка под кнопкой |
| `{{exe_mb}}` | размер `.exe`, после `build_exe()` | да, строка под кнопкой |
| `{{unitypy}}`, `{{fonttools}}` | версии пакетов | нет |
| `{{shot:ИМЯ\|подпись}}` | `release/press/ИМЯ` | `00-hero.gif`, иначе `01-dialogue.png` в шапке, `10-installer.png` и `02-language.png` в шагах установки |
| `{{gallery:ИМЯ\|подпись; ИМЯ\|подпись; …}}` | `release/press/` | сетка 03–09 в «Как это выглядит» |
| `{{video}}` | ссылка из `release/press/video.txt` | да, «Как это выглядит» |
| `{{video:installer}}` | ссылка из `release/press/installer.txt` | да, «Установка» |

Поддержка всех подстановок в коде осталась; неиспользованные просто не стоят в шаблоне.
Картинка `graphics-progress.svg` по-прежнему собирается (`write_graphics_bar`),
но README на неё больше не ссылается.

**Кадра нет — ничего не ломается.** `{{shot:…}}` без файла превращается в пустую строку
(в лог: «кадра нет, пропускаю»). `{{gallery:…}}` ставит в таблицу по два в ряд только
те кадры, что есть, с подписью под каждым; нет ни одного — пусто. После подстановок
`drop_empty_sections()` убирает заголовок `##`–`######`, под которым ничего не осталось,
— так раздел «Как это выглядит» не висит пустым, пока нет ни кадров, ни ролика.
Поэтому в шаблоне в блоках кода не писать строк, начинающихся с `# ` (их можно принять
за заголовок), а раздел, который должен остаться даже пустым, не делать из одних подстановок.

**Ролики по имени.** `{{video:ИМЯ}}` читает `release/press/ИМЯ.txt`, `{{video}}` —
`video.txt`. Файла нет — плеера нет. `{{shot:a.gif,a.png|…}}` берёт первый существующий
кадр: так гифка в шапке подменяет статичный кадр.

**Обратная связь.** Пока — раздел «Нашли ошибку?» со ссылкой на Issues. Когда появится
сообщество ВК, раздел переименовать в «Связь»: ошибки в переводе — GitHub или ВК
(решение пользователя от 6 ноября 2026; «пожелания и болтовня» не писать).

### Описание счётчика картинок

> HD и обычные версии считаются отдельно. Картинки без текста и надписи,
> которые решено оставить в оригинале, в счётчик не входят. Учтена графика,
> которая поставляется с патчером; общие экраны запуска сборника не считаются.

### Технические подробности установки

> Русский занимает слот немецкого языка, но содержимое слота целиком берётся
> из английской локализации, и перевод кладётся поверх. Немецкого в игре не остаётся
> нигде — включая первую игру, надписи на картинках, заставки и выкрик «Objection!».

> Патчер сначала проверяет папку рядом с собой, текущую папку и библиотеки Steam.
> Если там игры нет — ищет на подключённых локальных дисках, включая USB.
> Распознаёт её по файлу `GK12.exe` и папке `GK12_Data`; Steam для поиска не нужен.
> Обход дисков может занять несколько минут, во время поиска виден прогресс.
> Недоступные папки пропускаются, сетевые диски не обходятся.

> Первая установка занимает **около двенадцати минут**, и почти всё это время
> занимают два шага: пересборка гарнитур (в игре нет кириллицы, её приходится
> «доучивать») и замена немецких надписей на английские.

> `--preview` показывает оформление без установки, `--console` запускает консольный режим.

### Почему это безопасно — полная версия

> **Собирает перевод из вашей игры.** Исходные игровые бандлы в комплект не входят.
> Маленькая иконка установщика — лицо Эджворта из ретро-графики.
> Патчер берёт **вашу** английскую версию и собирает из неё русскую прямо на месте.
> Даже надписи на картинках едут не картинками: в комплекте только наши пиксели —
> русские буквы и то, что легло под снятую английскую надпись, — а на вашу английскую
> картинку их накладывает сам патчер. Поэтому же он переживает обновления игры:
> файлы ищутся по имени, а не по контрольной сумме.

> **Показывает исходники.** В папке `patcher/` лежит тот же код, из которого собран
> `.exe`, — не «похожий», а ровно тот: `.exe` собирается из этой папки, и ничего сверх
> неё в нём нет. Кто не хочет запускать чужой бинарник, запускает скриптом и получает
> тот же результат — файлы игры выходят байт в байт одинаковыми, это сверено
> контрольными суммами.

Всё это по-прежнему подробно — в [`release.md`](release.md) («Что делает патчер»,
«Откуда патчер берёт код», «Замеры, на которые опирается витрина»).
