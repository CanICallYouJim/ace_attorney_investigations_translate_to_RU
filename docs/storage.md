## Автоматически

Задача планировщика Windows `AAI2-SafeCleanup`, ежедневно в 12:00 по Москве, обычные права
текущего пользователя, запуск при доступности после пропущенного времени.
Работает, когда пользователь вошёл в систему; окно скрыто через `pythonw.exe`.
Действие: `.venv/Scripts/pythonw.exe tools/cleanup.py --apply --user-caches`.
Задача зарегистрирована, Windows вернула состояние Ready; первого планового запуска
при записи отчёта ещё не было.

Точный список удаления хранится в `tools/cleanup.py`: промежуточные сборки,
кэши скачанных пакетов pip/npm и только `.hprof` в `PyCharm*/tmp/hprof-temp`.
Никаких широких правил `*.png`, `*.tmp`, всего AppData или пользовательского Temp.
Автоматически — только файлы старше семи дней по времени создания и изменения;
сборка со свежим файлом сохраняется целиком. Ссылки и junction не обходятся.
Файлы с ошибкой удаления остаются на месте и попадают в отчёт, код возврата ненулевой.
Для сборки списка требуется доступ к папкам; ошибка доступа прерывает запуск.

Ручной просмотр: `.venv\Scripts\python.exe tools/cleanup.py --user-caches`.
Ручной запуск с теми же ограничениями: `make tidy`.
`--now` снимает защитный срок и допустим только при отдельной осознанной уборке.
Первичный подробный отчёт сохранён в `work/cleanup/2026-10-27-initial.json`.
Последний подробный отчёт перезаписывается в `work/cleanup/latest.json`, без накопления логов.
Отключение: Планировщик заданий → AAI2-SafeCleanup → Отключить.
После переноса проекта путь в задаче нужно изменить.

## Правило для следующих сессий

Временную работу создавать через `TemporaryDirectory` с гарантированной уборкой
(`with` / `finally`). Большие промежуточные сборки после проверки и установки
не копить; перед завершением сессии запускать `tools/cleanup.py --apply`.
Общий сборщик оставляет свежие файлы ещё на семь дней ради параллельных сессий;
свою временную папку закрытая операция удаляет сразу.
Новые категории сначала описывать здесь и добавлять точным ограниченным путём;
не расширять список до рисунков, истории, резервных оригиналов и личных файлов.

Проверено на отдельной временной папке: предварительный просмотр ничего не удаляет,
свежая сборка сохраняется, удаление ограничено списком, объём считается по удалённым файлам.
