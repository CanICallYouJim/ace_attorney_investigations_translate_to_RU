## Охват и доказательства

- Все 164 живых бандла плюс `data.unity3d` и `unity default resources`:
  109709 объектов, 127775 строковых полей и кандидатов, ошибок чтения 0.
- Для 5443 объектов без схемы использован обход выровненных строк с длиной
  в сырых данных. Это эвристика, а не восстановленная схема. У 5442 компонентов
  `data.unity3d` дополнительно разрешены класс скрипта и владелец GameObject.
- Потоковый читатель держит ограниченное число распакованных блоков. Проверен
  против штатного UnityPy на всех 61 объектах трёх независимых небольших бандлов:
  SHA256 сырых данных совпали, включая чтение в обратном порядке.
- Из IL2CPP metadata извлечены 63302 строковых литерала, отобраны 4389
  многословных кандидатов. Новая действующая таблица GK2 не подтверждена.
  Это поиск по кандидатам, не ручное чтение всех литералов.
- Дополнительно просмотрены 362 текстуры на 19 контактных листах: общие
  интерфейсы, ресурсы сцен, старые атласы и материалы моделей. Это дополнение
  к существующей переписи графики, не утверждение о ручном осмотре каждого
  пикселя всех языковых копий. Все 246 записей слоя сверены с живыми адресами;
  три splash-атласа проверены отдельно с учётом размещения.
- Остальные файлы установки перечислены отдельно: конфигурации, внешние
  потоки ресурсов, платформенные библиотеки. Резервные копии не считаются живыми.

Три фоновые ошибки подтверждены глазами по декодированному изображению,
полученному через container → Sprite → texture, а не по имени текстуры.
Сравнения `visual/compare_03.jpg`, `compare_04.jpg`, `compare_05.jpg` показывают
живую и принятую версии с одинаковым усилением яркости ×12 для чтения тёмных букв.
`_07` перепроверен: русский, ошибки нет. Первоначальное предположение о четырёх
ошибках исправлено. Поле `texture_sha` слоя содержит исходник, поэтому его
несовпадение с текущей текстурой само по себе не является дефектом.

Числовой допуск сравнения пропустил три английских фона: средняя разница по всему
кадру меньше 2, нет разницы больше 64. Для тёмных надписей такой допуск недостаточен.
Итог 243 числовых соответствия / 3 визуально подтверждённых ошибки не является
гарантией качества каждой картинки. Зелёный старый selftest не опровергает находки.

## Разобранные ложные срабатывания и прежние долги

- `Complete!`: у семи подписей найден LocalizeStringEvent с `set_text`;
  исходная надпись prefab не равна тексту после локализации. Аналогично `Loading`.
- 118 `Music Name` — заполнители динамического интерфейса галереи, не 118 новых
  уникальных строк. Пять старых подписей достижений также отделены от таблиц.
- Имена ресурсов, диагностические сообщения, лицензионные тексты и японские
  атласы старого интерфейса не добавлены к долгу сюжетных реплик GK2.
- Реплики: 33422 заполнены, включая 74 сознательные заглушки DEMO TEXT.
  Таблицы: 2823 = 2517 заполненных + 47 исключений + 259 отложенных.
  Сверка обеих пар таблиц с установкой ранее дала 0 отсутствующих и 0 расхождений.
- Сохраняются прежние открытые позиции: обложка `map0d_cm` и 18 английских
  голосовых выкриков по описи. Нового прослушивания аудио не проводилось.
- `check_all.py --build` ранее в этом аудите: 14/14. После этого менялись только
  инструменты аудита и отчёты; результат не выдаётся за проверку новых установок.

Новых переводческих решений в этом проходе не принималось. Следующий шаг —
устранить три подтверждённые ошибки установки, затем проверить их в игре;
для 20 legacy-строк проверить достижимость, сохраняя их в учёте до решения.
