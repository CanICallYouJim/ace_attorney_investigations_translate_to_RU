## 2. Сцена

```bash
python3 tools/scene_dump.py <сцена> --cast                     # кто говорит в сцене и сколько
python3 tools/scene_dump.py <сцена> --langs ger,fre --codes   # говорящий, EN, нем., фр., RU с кодами
python3 tools/scene_dump.py <предыдущая сцена> --ru-only       # что было до — для связности
```

Говорящий у каждой реплики — точный (код E101 из игры). **Адресат** — по сцене: кто
стоит перед говорящим (правило №8). Немецкий `du/Sie` и французский `tu/vous` —
подсказка к форме, но решение проекта важнее: если `address.md` говорит «ты»,
а у немцев `Sie` — «ты» (так решено для Эджворта↔Гамшу, Ланг→Эджворт и др.).
Граница обращения (Кей до и после того, как её узнали; «???» до того, как назвался) —
**по плашке говорящего**, а не по номеру блока: пока собеседник подписан «???»,
он для говорящего ещё незнакомец; как только на его репликах в той же сцене имя —
граница пройдена. Пилот `sce3_c0_01`: два места Эджворт → Кей стояли на «вы»
уже после узнавания (блоки под плашкой «Кей»), а редактор судил по порядку блоков.
Немцы и французы для этой границы не подсказка. Сверяй и с копиями: `copies.py`.
Для других языков в сомнении: `python3 -c` по `work/review/locales/<lang>.json`
(eng, fre, ger, jpn, kor, sim, tra) — ключ тот же id.

## 3. Как править

Порядок внутри реплики: **L0** (смысл, имя мимо глоссария, коды) → **L1** (ты/вы,
род обращения) → **L2** (калька, странный оборот, идиома словами) → **L3** (слово
не по образу/не по месту) → **L4** (частицы, порядок слов «новое в конец», ритм,
однообразие). Реплика может получить правки нескольких уровней сразу.

- **Точечно.** Меняешь слово или оборот, а не переписываешь реплику. Нормальная,
  живая реплика — не трогать; правка ради правки — брак. Ожидаемая доля правок —
  порядка 5–15 % реплик сцены; больше — только если сцена правда плохая.
- **Тест на кальку:** закрой английский и скажи мысль так, как сказал бы этот герой
  в этой ситуации по-русски. Потом сверь смысл с английским.
- **Не терять:** смысл, подсказку к загадке, шутку, напряжение и настроение сцены,
  характер героя, связь с соседними репликами (кто-то повторяет слово — повтор должен
  выжить).
- **Не заменять штамп другим штампом** («похоже» → «видимо» → «кажется»). Вводное
  чаще убрать или перестроить фразу. Одна доза нажима на реплику.
- **Коды `{E…}`** — набор как в английском (порядок можно менять). `\n` — перенос
  строки; в окне 2 строки, строка ≤ 50 (жёстко 53).
- **Ключ патча — полный id с `.bytes`.**

### Сейчас НЕ трогать (ждут решения пользователя)

Если наткнулся — не правь, а положи в вопросы с `kind: "dec-pending"`:
- у Эджворта: «ну» можно на запинке/подгоне; «извольте» — только ирония или официальное требование; «отнюдь», «полноте» — нельзя (решение 6 нояб.);
- время: в речи словами («около девяти утра»), считанное с документа — цифрами по 24 часа («6:42», «22:15»); «Тортофеерия в 3 часа» — как есть (решение 6 нояб.).

**Тире (решено 5 ноября):** `--` только слитно со словом, где речь обрывается («зна--», «Чт--!?»); обычное тире — «—».

### Решения, а не перевод — вопросом, не правкой (правило №4)

Имена, клички, термины глоссария (`kind: "term"`), каламбуры, заменённая идиома,
вывеска, лозунг, ключевое слово логики, присказка персонажа, смена голоса героя
(например, «ну» в речи Эджворта) — **не менять самому**. Вопрос в `.questions.json`
(форма — brief.md §7). Исключение: явная ошибка против уже записанного решения
(имя мимо глоссария, «Симеон» вместо «Семён», «Ванюша», «Актёркин») — чинить.

### Копии

Реплики из `*_partner`, служебные («Больше тут…», уведомления органайзера), флешбэки
и повторённые разговоры игра хранит копиями. Все копии своей правленой реплики находит

```bash
python3 tools/copies.py "<полный id>"
```

(`=` — русский совпадает с твоим нынешним, `≠` — копия уже разошлась). Правило:
копии звучат **одинаково с поправкой на адресата** — другая форма ты/вы или род
по другую сторону границы обращения законны и сохраняются. В `.why.json` у такой правки:

- `"copies": ["id", ...]` — копии, в которые главная ветка разнесёт ту же правку
  (с поправкой на форму — опиши её в `"copies_note"`, если она нужна);
- `"copies_diverged": ["id", ...]` — копии, которые уже были переведены иначе до тебя;
  в `"copies_note"` скажи, к чему сводить (к твоему варианту — обычно да, если он лучше).

Сам копии в чужих сценах в патч не клади — разносит главная ветка.

## 4. Выдача

В каталог, который назван в твоём задании (например `work/proofread-2026-11/c4/`),
для каждой сцены:

- `<сцена>.patch.json` — `{id: новый ru целиком}`, только изменённые;
- `<сцена>.why.json` — `{id: {"level": [...], "was": "...", "why": "...", "copies": false}}`;
- `<сцена>.questions.json` — список вопросов (может быть пустым `[]`).

Сцена без правок — всё равно три файла (`{}`, `{}`, `[]`).

**Перед сдачей обязательно:**
```bash
python3 tools/proof_check.py work/proofread-2026-11/c4/<сцена>.patch.json
```
Ноль ошибок `✗`. Предупреждения про смену ты/вы — перечитай каждое: смена должна
быть намеренной. Потом перечитай свои правки ещё раз глазами, только русский:
порядок слов, частица одна, отклик сходится с репликой выше.

(было → стало, одна строка «почему»), число вопросов. Без пересказа сюжета.
