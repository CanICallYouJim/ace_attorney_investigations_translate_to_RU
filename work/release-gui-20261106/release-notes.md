Новый графический установщик русской локализации AAI2.

- Фон из игры и фоновая музыка с громкостью 35%; звук можно выключить кнопкой.
- Плавные полосы прогресса с движущимися диагоналями и отдельными этапами установки.
- Проверка данных всех пяти глав перед установкой.
- Большая кнопка «Устанавливается…» с вращающимся индикатором.
- Живой журнал установки с полными сообщениями об ошибках и трейсбеками.
- Иконка EXE, окна и панели задач — лицо Эджворта из ретро-графики игры.

При обычном запуске откроется окно; нажмите «Установить перевод».
`--preview` показывает интерфейс без установки, `--console` сохраняет консольный
режим. Проверка, сборка в отдельную папку и откат по-прежнему доступны через CLI.

Фон и музыка берутся из вашей установленной игры. В комплект включена только
маленькая ретро-иконка; игровые бандлы не распространяются.

Перевод сохранён из предыдущего выпуска: 33 422 из 33 422 реплик, 2517 из 2823 строк,
244 картинки и 2 материала. Выберите в игре язык «Русский».
